01 / Machine Learning

Bahrain Rental Price Prediction Challenge

🥈 3rd Place — Kaggle Competition

A machine learning project focused on predicting monthly rental prices for properties in Bahrain. Involved cleaning real-world property listing data, handling missing values and duplicates, exploratory data analysis, feature engineering, and categorical/numerical preprocessing. Engineered property-related features, analyzed rental price distributions, and evaluated models using Mean Absolute Error (MAE), the competition's evaluation metric. Submitted to the Bahrain Rental Price Prediction Challenge on Kaggle.

05 / Application

Ctrl + Eat — Recipe Manager

An interactive recipe management application built with Python, Streamlit, and Pandas for organizing, searching, and exploring a local recipe database. Features include adding and validating new recipes, searching by ingredient, browsing the full collection, sorting by rating, filtering by category, and a random "Surprise Me" recommendation. Uses Pandas string filtering for ingredient search and custom ranking logic for sorting, with recipes stored in a CSV file behind a Streamlit interface styled with custom HTML/CSS.

07 / Graph Theory

Graph Theory — Connectivity & Bipartite Graph Analysis

An academic Graph Theory project developed in MATLAB, focused on analyzing graph properties, connectivity, and structural characteristics. Implemented algorithms to identify bridges and cut vertices, determine whether a graph is bipartite, and generate a valid 2-coloring when applicable. Graphs were represented using adjacency matrices and processed programmatically to analyze and visualize the resulting properties.

MATLABGraph TheoryAdjacency MatricesGraph Algorithms

Numerical Integration — Newton-Cotes Methods Comparison

An academic Numerical Analysis project developed in MATLAB, focused on numerical integration and the comparison of Closed Newton-Cotes formulas. Involved implementing numerical integration methods in MATLAB, comparing their accuracy and performance, and analyzing the mathematical concepts behind each method. Results and mathematical documentation were prepared using LaTeX, alongside a presentation explaining the methods, calculations, and findings.
